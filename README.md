# UPI Transaction Decline Analysis

## Project Overview

Analyzed NPCI UPI transaction data using Power BI to identify Business Decline patterns, prioritize high-impact banks, and propose product improvements.

## Problem Statement

The project investigates Business Decline patterns across major UPI remitter banks and identifies opportunities to reduce transaction friction.

[View The Project →](https://app.notion.com/p/3c2b76c92aef80d4a4c7f6a4bb8e8230?source=copy_link)

## Dashboard

The Power BI dashboard analyzes:
- Overall transaction volume
- Approval rate
- Business Decline rate
- Technical Decline rate
- Bank-wise Business Decline volume
- Business vs Technical Decline rates

## Key Finding

Business Declines were significantly higher than Technical Declines, indicating Business Decline reduction as the primary improvement focus.
